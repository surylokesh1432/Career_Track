# Career_Track
html5, css3, javascript, frontend, job-tracker, career-management, responsive-design

CareerTrack
CareerTrack is a personal job search management application designed to help job seekers organize, track, and manage their job applications and interview progress in one place.
The project provides a centralized dashboard to monitor application statistics, maintain company and job details, track interview schedules, manage preparation notes, and showcase professional skills and projects.
Key Features

Dashboard: View total applications, interviews, offers, and rejections.
Application Tracker: Add and manage company names, job titles, locations, job URLs, application dates, and application statuses.
Interview Tracker: Record interview dates, interview types, company details, and preparation notes.
Profile Page: Showcase professional information, technical skills, learning progress, and projects.
Resume Access: Provide a downloadable resume.
Responsive Design: Designed to work across desktop, tablet, and mobile devices.

Technologies Used

HTML5 — Page structure and semantic elements.
CSS3 — Styling, layouts, Flexbox, Grid, animations, and responsive design.
JavaScript — Planned for interactive functionality and dynamic data management.
React — Planned for a future frontend implementation.

Project Goal
The goal of CareerTrack is to make job searching more organized and manageable by bringing application tracking, interview preparation, and career progress together in one application.
